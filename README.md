# Tabula Rasa

*"L'homme peut faire ce qu'il veut, mais il ne peut pas vouloir ce qu'il veut."* — Schopenhauer

Un jeu émergent où le monde se crée par vos actions.

## Jouer

**[narciss666.github.io/Tabula_rasa](https://narciss666.github.io/Tabula_rasa/)**

- Mobile : joystick tactile (gauche) + bouton interaction (droite)
- PC : WASD + Espace/E

## Concept

Pas de quête. Pas de but. Pas d'explication. Le Director IA observe chaque action et génère le monde en réponse. Chaque partie est unique.

## Stack

- Vanilla JS / Canvas 2D
- Director : Claude Sonnet (API Anthropic)
- Monde procédural infini par chunks
- Persistance localStorage
